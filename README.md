# Portfólio Pessoal – Josicleide Salustiano

## Sobre o projeto
Este portfólio foi desenvolvido como atividade do curso de Desenvolvimento de Sistemas. O objetivo é apresentar um pouco sobre mim, meus conhecimentos na área de tecnologia e os projetos que desenvolvi durante o curso.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- GitHub Pages

## Link do site publicado
Em breve, disponível pelo GitHub Pages.

## Funcionamento do projeto
O site possui um menu de navegação que permite acessar as seções de Perfil, Projetos, Habilidades e Contato. O layout foi desenvolvido utilizando Bootstrap para facilitar a organização e adaptação em diferentes tamanhos de tela.

## Recurso novo adicionado
Foi adicionada uma animação nos cartões da seção de projetos. Ao passar o mouse sobre os cartões, eles se movimentam suavemente para cima e apresentam uma sombra.

## Como o recurso foi implementado
O efeito foi implementado utilizando CSS, com a propriedade transition para criar uma transição suave e a propriedade transform: translateY() para movimentar os cartões. Também foi utilizado box-shadow para destacar os projetos.
